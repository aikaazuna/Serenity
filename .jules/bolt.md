## 2024-05-16 - Audio Visualizer State Thrashing | **Learning:** High-frequency visual updates (like 60fps VU meters) relying on React state (`setState` inside `requestAnimationFrame`) cause massive fiber tree re-evaluations and layout thrashing, killing performance. Also, subscribing to a rapidly updating whole-object state in Zustand triggers unnecessary renders in un-related sibling components. | **Action:** Always bypass React for high-frequency animations (mutate DOM via refs directly) and use atomic Zustand selectors (select specific keys) for frequently updated global state.
