## 2026-09-18 - Missing ARIA Labels for Action Buttons **Learning:** Icon-only action buttons (e.g., delete, toggle state, clear search) often use 'title' attributes but lack corresponding 'aria-label' attributes for screen reader accessibility in this application. **Action:** During accessibility reviews, explicitly check icon-only buttons for both visual tooltips ('title') and programmatic labels ('aria-label'), adding dynamic or static ARIA labels as appropriate.

## 2026-09-18 - Tooltips vs ARIA labels **Learning:** Some icon-only buttons rely on 'title' attributes to show a tooltip on hover, which are not accessible for screen readers. In these cases 'aria-label' attributes must also be added. **Action:** Ensure that all buttons, especially icon-only ones, have 'aria-label' attributes, even if they have 'title' attributes.
